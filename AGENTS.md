# Agent Instructions

Guidance for AI coding agents working in this repository: boilerplate-web, the starting point for a new Next.js app. This file does not restate project details; it points at the canonical docs, which drive the implementation.

The standards are supplied by the vendored skills in `.claude/skills/` / `.agents/skills/`, which load automatically via skill discovery. The `docs/prd/` pipeline ships as templates: fill each stage in order before building, and replace the `<angle-bracket>` prompts with the project's own facts.

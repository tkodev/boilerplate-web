# Plan

The plan: the working loop's plan-implementation output
([process](../01-standards/process.md) §Milestones), the final stage of the PRD
pipeline. The milestone list below is the whole plan: each milestone's scope,
with its status carried by the checkbox (`[ ]` todo, `[~]` in progress,
`[x]` done). Milestones run in listed order. Tasks are cut at each milestone's
plan step ([process](../01-standards/process.md) §The delivery cycle) and tracked
as branches and PRs, not listed here.

The canonical arc: foundations (system) → the proving surface → the remaining
surfaces in parallel → polish and launch sweeps. Parallelism is earned: it begins
only once the proving surface's gate passes.

## The milestones

- [ ] **m01 — Foundations** *(system)*
  - Scaffold, tooling, tokens, fonts, data, shell, `/design` specimen
- [ ] **m02 — <The proving surface>** *(surface)*
  - <The riskiest or most representative surface, built through every layer end to
    end; named by [02-observations.md](02-observations.md) §What to Prototype First.
    Its gate unlocks surface parallelism.>
- [ ] **m03 — <Surface>** *(surface)*
  - <Scope.>
- [ ] **m04 — Polish** *(sweep)*
  - Coherence pass: metadata and OG per route, error and not-found surfaces
- [ ] **m05 — Launch** *(sweep)*
  - SEO verified, analytics live, performance budgets met, domain cutover
